# Ancien déploiement Raspberry Pi 5 — Abandonné

> **Décision du 20 octobre 2026 :** eHome EMS est exclusivement une intégration personnalisée Home Assistant distribuable via HACS. L'ancien serveur autonome RPi5/NVMe, Docker, FastAPI et React ne fait plus partie du projet.

**Ne pas suivre les anciennes instructions de déploiement RPi5 pour eHome EMS.** Aucun Raspberry Pi supplémentaire n'est nécessaire. L'intégration utilisera les entités et services de Home Assistant existant.

Références : [cahier des charges actuel](CAHIER_DES_CHARGES.md) · [README](../README.md) · [guide d'accueil](wiki/Home.md).

Les autres pages historiques d'installation RPi5 du répertoire `docs/wiki/` sont également obsolètes et seront archivées ou remplacées.
